# منار للتربية الإسلامية

منصة عربية لمراجعة التربية الإسلامية للأولى باكالوريا بالمغرب.

## النشر على GitHub Pages

1. فك ضغط هذا الملف على حاسوبك.
2. افتح مستودع manar-islamic-education ثم Add file > Upload files.
3. ارفع جميع الملفات ومجلد references معًا. يجب أن يظهر index.html في المستوى الرئيسي للمستودع، وليس داخل مجلد إضافي.
4. إذا كان هناك README.md سابق، يمكن استبداله بهذا الملف.
5. اضغط Commit changes.
6. افتح Settings > Pages واختر Deploy from a branch، ثم main والمجلد /(root)، واضغط Save.
7. انتظر اكتمال النشر، وافتح الرابط الذي يعرضه GitHub في صفحة Pages.

لا ترفع ملف ZIP نفسه؛ ارفع محتوياته بعد فك الضغط. مجلد references يحتوي ملفات PDF المستخدمة في روابط الدروس، ويجب رفعه كاملًا.

## المحتويات

- index.html: الصفحة الرئيسية.
- style.css: التنسيق والاستجابة والطباعة A4.
- data.js: بيانات الدروس والشواهد والأسئلة.
- content-update.js: المحتوى المراجع وفق الملفات المرفقة.
- app.js: البحث والتصفية والأسئلة وحفظ التقدم.
- references/: ملفات الدروس والإطار المرجعي.

المنصة لا تحتاج تثبيتًا أو خطوة بناء أو خادمًا. خط Cairo يتم تحميله عند الاتصال بالإنترنت مع خط بديل متاح. يُحفظ تقدم الطالب في متصفحه، ولا يتزامن بين الأجهزة.

## المحتوى والمراجع

ملخصات الدروس العشرين موسومة بإعداد الأستاذ محمد الباركي. محاور المراجعة وتوزيع المهارات وفق الإطار المرجعي المرفق لسنة 2016، دون ادعاء اعتماد إطار دورة 2027. تفاصيل المصادر وحدود المحتوى متاحة داخل المنصة.

لم تضف رخصة مفتوحة للملفات التعليمية. عند نشر المستودع بصيغة Public تصبح ملفات الموقع وملفات PDF قابلة للاطلاع والتنزيل.
